# 문서 규칙

## 자리
| 폴더 · 파일 | 무엇 | 쓰는 법 |
|---|---|---|
| `AGENTS.md` · `CLAUDE.md` | 진입점 | 꼭 지킬 몇 줄 + 포인터만. 내용을 쓰지 않는다 |
| `docs/rules/` | 지켜야 할 것 | 항목 하나 = 파일 하나. 짧게, 이유는 결정 로그 링크로 |
| `docs/decisions.md` | 결정 로그 | 추가만. 바꾼 결정은 새 줄로 쓰고 옛 줄에 `→ 대체: 날짜` |
| `docs/prd/` | 시험 중인 기획 | 자유 형식. 여기 있는 것은 아직 굳지 않았다 |
| `shorts/<번호>-<주제>/RECORD.md` | 한 편의 기록 | 추가만. 사용자 원문을 남긴다 |
| `docs/sessions/` | 세션 회고 · 인계 · 반복 패턴 | 세션 파일은 추가만. `README.md` 의 "다음 할 일"이 정본. 쓰는 법은 `.claude/skills/session-wrap/` |

## 원칙
- **정본은 한 곳.** 같은 내용을 두 곳에 쓰지 않는다. 다른 곳에서는 링크만 건다.
- **포인터는 한 단계.** 진입점 → 정본으로 바로 닿게 한다. 정본이 다른 정본을 길게 따라가게 하지 않는다.
- 문서마다 맨 위에 "본 범위 · 보지 않은 것"이나 기준 날짜를 둔다(언제 기준의 사실인지).

## prd → 정식 자리로 옮기는 기준
`docs/prd/` 의 내용은 사용자가 결정하면 옮긴다.
1. 결정 자체 → `docs/decisions.md` 에 한 줄.
2. 지켜야 할 것 → `docs/rules/<항목>.md`.
3. prd 문서의 그 자리에는 `→ 옮김: <링크>` 만 남긴다.

아직 만들지 않은 자리(필요해질 때 만든다): `docs/adr/`(결정 로그가 길어지면 큰 결정만 따로), `docs/research/`(조사 기록이 prd 밖에서도 쓰이면), `docs/guides/`(절차가 굳으면).
