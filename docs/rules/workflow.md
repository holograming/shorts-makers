# 일하는 방식

- **에이전트가 묻고 사용자가 결정한다.** 결정 지점에서는 선택지 + 추천 하나를 내고 기다린다. 임의로 넘기지 않는다.
- 사용자 기본값을 에이전트가 바꾸지 않는다. 위험(저작권 등)이 보이면 알리고, 고르는 건 사용자.
- 형태를 추측해 전체 렌더부터 하지 않는다. **형태 샘플 프레임**을 먼저 보여 주고 고르게 한다(v1 교훈).
- 결과물은 프레임 몇 장으로 직접 확인한 뒤 보여 준다.

## 결정 지점
1. **결정 1** — 이해 직후: 질문 · 남길 대목 · 예상 길이 후보 + 형태 샘플 프레임.
2. **결정 2** — 렌더 후: 미리보기 → 올림 / 수정(한 줄 지시) / 버림.
3. **결정 3** — 주 1회: 이번 주 판단 중 세컨브레인에 남길 것.
- 답이 없으면 48시간 뒤 `보류`. 자동으로 넘기지 않는다.
