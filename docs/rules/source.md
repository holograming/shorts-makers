# 원본 · 자막 · 저작권

## 원본
- **원본은 주제의 핵심을 확인하는 데만 쓴다.** 원본의 40% 미만, 대개 훨씬 적게. 쓸 대목은 사용자가 정한다.
- **남긴 대목은 비틀지 않는다.** 화면을 자르거나 흐리게 깔지 않는다. 박힌 자막도 그대로 둔다(오역하지 않는다는 뜻). 뜻이 달라지게 말을 자르지 않는다.
- 영상의 주인공은 **내 생각과 근거**다. 내 말은 해설 장면에, 뒷받침 정보는 근거 장면에 둔다.

## 내 글자 (보류 — 2026-11-13)
- 처음 규칙: 자막은 원문 번역이 아니라 **내 문장**, 필체는 Pretendard Black(두꺼운 고딕) 고정.
- 원본 자막을 그대로 두기로 하면서(2026-11-12) 이 규칙이 어디까지 적용되는지(해설 장면만? 필체 고정 유지?)는 사용자가 보류했다. 정할 때까지 묻는다.

## 하지 않는 것
- 감지 회피 기법(반전 · 속도 · 피치 변조 등)은 넣지 않는다.

## 저작권
- **형식으로 다룬다.** 짧은 핵심 인용 + 내 해설 · 근거가 대부분인 구성이 곧 공정이용 쪽 설계다. 원본 비중을 늘리고 싶어지면 그때 알린다.
- 참고: Content ID · Meta 매칭은 화면 · 오디오 지문으로 잡는다(감지 자체는 피하지 못함). 감지 회피는 하지 않는다.
