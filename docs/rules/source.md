# 원본 · 자막 · 저작권

## 원본
- **원본은 주제에 맞게 골라 줄인다.** 원본은 대체로 길고 주제와 맞지 않는 내용도 섞여 있다. 남길 대목은 사용자가 정한다.
- **남긴 대목은 그대로 둔다.** 화면을 자르거나 흐리게 깔지 않는다. 박힌 자막도 그대로 둔다(오역하지 않는다는 뜻). 뜻이 달라지게 말을 자르지 않는다.
- 내 말(이해 · 정리 · 판단)은 원본 위가 아니라 **따로 만든 해설 장면**에 둔다.

## 내 글자 (보류 — 2026-11-13)
- 처음 규칙: 자막은 원문 번역이 아니라 **내 문장**, 필체는 Pretendard Black(두꺼운 고딕) 고정.
- 원본 자막을 그대로 두기로 하면서(2026-11-12) 이 규칙이 어디까지 적용되는지(해설 장면만? 필체 고정 유지?)는 사용자가 보류했다. 정할 때까지 묻는다.

## 하지 않는 것
- 감지 회피 기법(반전 · 속도 · 피치 변조 등)은 넣지 않는다.

## 저작권
- Content ID · Meta 매칭은 화면 프레임 · 오디오 지문으로 잡는다. 자막 · 필체를 바꿔도 감지는 피하지 못한다.
- 비공개 계정으로 시작하므로 감지돼도 영향이 작다. **공개 전환 때 다시 판단한다.** 원본을 길게 쓸수록 위험이 크다.
