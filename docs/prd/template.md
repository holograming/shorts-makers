# 템플릿 초안 — 원본 그대로 + 내 노트

상태: 초안(2026-11-13, 같은 날 수정 반영). 근거: [research-agentos.md](research-agentos.md). 굳는 항목은 [문서 규칙](../README.md)대로 rules · decisions 로 옮긴다.

## 한 줄
**영상 하나 = 내가 답하고 싶은 질문 하나.** 원본은 그 질문에 맞는 대목만 골라 줄이고(화면 · 자막 · 발언은 손대지 않음), 그 사이 해설 장면에 내 노트(용어 · 배경 · 대조 · 내 판단)를 둔다.

- **원본은 줄인다.** 원본은 대체로 너무 길고 주제와 맞지 않는 내용도 섞여 있다. 주제에 맞는 대목만 남긴다.
- **원본을 그대로 둔다는 뜻:** 남긴 대목의 화면 · 자막 · 말은 바꾸지 않는다. 뜻이 달라지게 자르지 않는다.
- **길이는 정하지 않는다.** 말하고자 하는 바가 길이를 정한다. 주제에 맞는 길이를 고르는 것도 결정 1 에서 함께 정한다.

AgentOS 와 같은 점: 원본을 주제에 맞게 골라 쓴다(40~68%), 해설 → 원본 대목의 반복, 질문 넘기기, 대조, 핵심어 마무리.
다른 점: 끝에 **내 판단**(내가 바꿀 한 가지)을 둔다. 구독 요청은 공개 전환 뒤에 붙인다.

## 뼈대
1. **질문 세우기** — 내가 답하고 싶은 질문 + 시청자 예측("당신이라면?"). 결론 · 펀치라인은 미리 말하지 않는다.
2. **소개** — 누구 · 출처(날짜) · 이 영상에서 볼 것. 카드는 3장 이하.
3. **뼈대 그림 그리기** — 영상 끝까지 쓸 그림 하나(표 · 그래프 · 단계 막대)를 비워 둔 채 보여 준다.
4. **본문: (해설 → 원본 대목) × N**
   - 해설: 앞 대목 정리 → 용어(3개 이하) · 배경 → 대조 확인 → **내 한 줄** → 다음 질문 넘기기.
   - 해설마다 뼈대 그림에 "지금 위치"를 찍는다.
5. **정리** — 뼈대 그림 완성 → 확인 보드 → 핵심어 → **내가 바꿀 한 가지** → 출처 → (공개 전환 뒤) **구독 요청**.

## 원본 종류별 변형
| 원본 | 본문 단위 | 바꿀 것 |
|---|---|---|
| 대담 | 질문 + 답 | 해설 끝 질문 = 다음 대목 진행자 질문 |
| 발표 · 강연(혼자 말함) | 장 | 해설이 묻거나 반론을 낸다. 화자보다 그림을 먼저 그린다 |
| 한국어 원본 | 장 | 원본 자막 그대로. 용어 대신 해석 · 듣는 법 · 그때 → 지금 |
| 여러 원본 | 출처가 바뀌는 장 | 장 제목에 출처 · 날짜. 주장과 사실을 나눈다 |
| 글 | 원문 단락 | 원문 화면(그대로)을 단락마다 띄우고 → 해설 |
| 직접 실험 | 실패 → 원인 → 반대로 | 결과 전에 "볼 것 세 가지" |

## 전달 장치
| 장치 | 무엇 | 푸는 문제 |
|---|---|---|
| 뼈대 그림 | 하나의 그림을 끝까지 채워 간다 | 긴 논증에서 길 잃음 |
| 개념 막대 | 원본 재생 중 위쪽에 얇게, 지금 개념에 불 | 해설 없는 긴 구간(원본을 자르지 않고) |
| 확인 보드 | 주장마다 확인됨(출처 · 날짜) / 미확인 / 그때 → 지금 | 대조가 필요한 곳에서 빠짐 |
| 건너뜀 표시 | 필요할 때 "원본 12:34–14:10 · 한 줄"로 어디서 가져왔는지 · 무엇을 뺐는지 | 줄인 편집이 뜻을 바꿨다는 의심 |
| 내 한 줄 | 해설 끝 동의 · 반대 · 써 보니 (사용자가 쓴다) | 판단 없는 요약, 기억이 안 남음 |
| 예측 질문 | 대목 전에 시청자가 답을 먼저 정한다 | 남의 이야기로 흘러감 |

## 리듬 규칙
- 제목 개념이 나오는 대목 앞에는 반드시 해설.
- 해설 없이 5분 넘게 가면 개념 막대를 띄운다(원본은 자르지 않음).
- 수치가 3개 이상이면 말하지 않고 그림 하나로.
- 해설은 원본이 곧 할 말을 미리 말하지 않는다. 펀치라인은 화자 목소리로.
- 내 글씨는 원본의 글씨 영역(자막 · 자막띠 · 그림 라벨)을 피한다.

## 정할 것 (사용자)
- 내레이션 음성을 넣을지(지금은 무음 + 글).
- 영어 원본의 번역 자막(원문 + "번역" 표시 두 줄로 검수?).
- 내 글자 규칙 범위(보류 중, [rules/source.md](../rules/source.md)).
- 공개 전환 때 원본 인용 규모의 저작권 판단, 구독 요청 문구.
