# 템플릿 초안 — 내 주제 + 원본 핵심 + 근거

상태: 초안(2026-11-13, 같은 날 수정 반영). 근거: [research-agentos.md](research-agentos.md). 굳는 항목은 [문서 규칙](../README.md)대로 rules · decisions 로 옮긴다.

## 한 줄
**영상 하나 = 중분류 주제 하나.** 원본에서는 주제의 **핵심 요소만 확인**하는 짧은 대목을 쓰고, 그 위에 **내 생각**과 주제를 **뒷받침하는 정보**를 얹는다. 포맷은 AgentOS 와 비슷하게(해설 → 원본 대목 → 해설).

- **주제는 중분류.** 너무 포괄적이면(예: "AI 의 미래") 8~10분에 담기지 않는다. 너무 좁으면 원본 한 마디로 끝난다. 예: "AI 비서를 감시하는 별도 AI(Sentinel)".
- **길이는 주제가 정한다. 기준은 8~10분.** 결정 1 에서 주제 크기와 길이를 함께 정한다.
- **원본은 핵심 확인용.** 원본의 40% 미만, 대개 훨씬 적게. 남긴 대목의 화면 · 자막 · 말은 비틀지 않는다(뜻이 달라지게 자르지 않음).
- **근거 장면.** 주제를 뒷받침하는 정보(공식 자료 · 논문 · 수치 · 다른 사례)를 찾아 중간에 넣는다. 필요하면 그 내용을 직접 만들어 본다(도식 · 재현 · 간단한 실험).
- **저작권은 형식으로 다룬다.** 짧은 핵심 인용 + 내 해설 · 근거가 영상의 대부분이 되게 만드는 것 자체가 공정이용 쪽 설계다. 따로 판단할 과제로 두지 않는다.

AgentOS 와 같은 점: 원본을 주제에 맞게 골라 쓴다, 해설 → 원본 대목의 반복, 질문 넘기기, 대조, 핵심어 마무리.
다른 점: 원본 비중이 훨씬 작고, **내 생각 · 근거 장면**이 주인공. 끝에 **내 판단**(내가 바꿀 한 가지). 구독 요청은 공개 전환 뒤.

## 뼈대
1. **질문 세우기** — 내가 답하고 싶은 질문 + 시청자 예측("당신이라면?"). 결론 · 펀치라인은 미리 말하지 않는다.
2. **소개** — 누구 · 출처(날짜) · 이 영상에서 볼 것. 카드는 3장 이하.
3. **뼈대 그림 그리기** — 영상 끝까지 쓸 그림 하나(표 · 그래프 · 단계 막대)를 비워 둔 채 보여 준다.
4. **본문: (해설 → 원본 핵심 대목 → 근거 장면) × N** — 근거 장면은 필요한 곳에만.
   - 해설: 앞 대목 정리 → 용어(3개 이하) · 배경 → **내 생각** → 다음 질문 넘기기.
   - 근거 장면: 원본 주장을 받쳐 주거나 반박하는 외부 정보(출처 · 날짜), 필요하면 직접 만든 재현.
   - 해설마다 뼈대 그림에 "지금 위치"를 찍는다.
5. **정리** — 뼈대 그림 완성 → 확인 보드 → 핵심어 → **내가 바꿀 한 가지** → 출처 → (공개 전환 뒤) **구독 요청**.

## 원본 종류별 변형
| 원본 | 본문 단위 | 바꿀 것 |
|---|---|---|
| 대담 | 질문 + 답 | 해설 끝 질문 = 다음 대목 진행자 질문 |
| 발표 · 강연(혼자 말함) | 장 | 해설이 묻거나 반론을 낸다. 화자보다 그림을 먼저 그린다 |
| 한국어 원본 | 장 | 원본 자막 그대로. 용어 대신 해석 · 듣는 법 · 그때 → 지금 |
| 여러 원본 | 출처가 바뀌는 장 | 장 제목에 출처 · 날짜. 주장과 사실을 나눈다 |
| 글 | 원문 단락 | 원문 화면(그대로)을 단락마다 띄우고 → 해설 |
| 직접 실험 | 실패 → 원인 → 반대로 | 결과 전에 "볼 것 세 가지" |

## 전달 장치
| 장치 | 무엇 | 푸는 문제 |
|---|---|---|
| 뼈대 그림 | 하나의 그림을 끝까지 채워 간다 | 긴 논증에서 길 잃음 |
| 근거 장면 | 주제를 받치는 외부 정보 · 직접 만든 재현을 중간에 | 남의 말 요약으로 끝남, 주장이 약함 |
| 확인 보드 | 주장마다 확인됨(출처 · 날짜) / 미확인 / 그때 → 지금 | 대조가 필요한 곳에서 빠짐 |
| 건너뜀 표시 | 필요할 때 "원본 12:34–14:10 · 한 줄"로 어디서 가져왔는지 · 무엇을 뺐는지 | 줄인 편집이 뜻을 바꿨다는 의심 |
| 내 한 줄 | 해설 끝 동의 · 반대 · 써 보니 (사용자가 쓴다) | 판단 없는 요약, 기억이 안 남음 |
| 예측 질문 | 대목 전에 시청자가 답을 먼저 정한다 | 남의 이야기로 흘러감 |

## 리듬 규칙
- 제목 개념이 나오는 대목 앞에는 반드시 해설.
- 원본 대목은 짧게(대개 1분 안팎). 길어지면 핵심만 남기고 나머지는 해설로 요약.
- 수치가 3개 이상이면 말하지 않고 그림 하나로.
- 해설은 원본이 곧 할 말을 미리 말하지 않는다. 펀치라인은 화자 목소리로.
- 내 글씨는 원본의 글씨 영역(자막 · 자막띠 · 그림 라벨)을 피한다.
