## 저작권 판단 (사용자 질문 "다른 쇼츠들은 어떻게 회피하나"에 대한 답)
- 자막 · 필체 · 내용을 바꿔도 Content ID · Meta 매칭은 **화면 프레임 · 오디오 지문**으로 잡는다 — 감지 자체는 피하지 못한다.
- 채널들이 쓰는 길: ① 화면을 직접 다시 만들기 ② 출처 밝힌 짧은 인용 + 논평(공정이용 근거, 감지는 됨) ③ 반전 · 속도 · 피치 변조(회피 기법 — **이 파이프라인에 넣지 않는다**).
- 사용자는 v1(①)을 보고 버리고 원본 편집을 골랐다. 비공개 계정으로 시작하므로 감지돼도 영향이 작다. 공개 전환 때 다시 판단한다.
