# 세션 파일 형식

파일명: `docs/sessions/YYYY-MM-DD-<slug>.md` (끝낸 날짜, slug 는 영문 두세 단어)

```md
# YYYY-MM-DD <한 줄 제목>

기준: <세션 시작 ~ 끝 날짜> · 브랜치 <이름> · 커밋 <첫 해시>..<끝 해시>
대화 원문: <jsonl 경로 또는 세션 링크> (로컬, 사라질 수 있음)

## 회고
### 한 것
- <결과물 · 결정 · 커밋, 링크로>
### 사용자 결정 · 교정 (원문)
- "<원문>" → <무엇이 바뀌었나>
### 잘 된 것
- <다음에도 할 방식>
### 잘못된 것
- <되돌림 · 헛걸음 · 다시 물은 것과 이유>
### 넘어온 것
- <이전 인계 중 못 한 것>

## 인계
### 상태
- <지금 어디까지>
### 다음 할 일 (추천 순서)
1. <...>
### 사용자가 정할 것
- <...>
### 로컬에만 있는 것 (지워져도 됨)
| 파일 | 다시 만드는 법 |
|---|---|
### 함정
- <다음 세션이 밟기 쉬운 것>
```

# patterns.md 형식

```md
# 반복 패턴

세 세션 이상에서 나오면 스킬 · 규칙 후보로 사용자에게 묻는다. 한 세션 안에서 여러 번은 1로 센다. 만들어지면 "됨" 칸에 링크.

| 패턴 | 종류 | 세션 수 | 세션 | 됨 |
|---|---|---|---|---|
| <같은 절차 · 같은 실수 · 같은 교정> | 절차/실수/교정 | 1 | [날짜](파일) | |
```
